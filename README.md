# Бот интерактивной очереди

Telegram-бот для управления очередью в групповых чатах.

## Возможности

- ✅ Создание очереди с названием
- ✅ Добавление пользователей в очередь
- ✅ Удаление из очереди
- ✅ Просмотр текущей очереди
- ✅ Движение очереди вперед с уведомлениями
- ✅ Проверка своей позиции
- ✅ Очистка и удаление очереди (только для админов)

## Команды

- `/start` - показать справку
- `/create [название]` - создать новую очередь
- `/join` - встать в очередь
- `/leave` - выйти из очереди
- `/show` - показать текущую очередь
- `/next` - вызвать следующего (убрать первого)
- `/myposition` - узнать свою позицию
- `/clear` - очистить очередь (только админы)
- `/delete` - удалить очередь (только админы)

## Установка и запуск

### Локально

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env`:
```env
BOT_TOKEN=your_bot_token_here
```

3. Запустите бота:
```bash
python main.py
```

### Docker

```bash
docker-compose up -d
```

## Структура базы данных

База данных SQLite с двумя таблицами:

- `queues` - хранит информацию об очередях
- `queue_members` - хранит участников очереди с их позициями

## Примеры использования

1. Создайте очередь:
   ```
   /create Очередь на консультацию
   ```

2. Пользователи встают в очередь:
   ```
   /join
   ```

3. Просмотр очереди:
   ```
   /show
   ```

4. Вызов следующего:
   ```
   /next
   ```

## Технологии

- Python 3.12+
- aiogram 3.x
